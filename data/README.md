# Data Documentation

The raw dataset contains marketplace search behavior, candidate products,
interaction labels, and product metadata.

The raw files are excluded from the public repository because of file size
and potential redistribution restrictions.

## Interaction Labels

| Label | Meaning |
|---|---|
| 0 | No interaction |
| 1 | Click |
| 2 | Cart |
| 3 | Purchase |

The processed datasets used for the Power BI dashboard are available in
the `dashboard_data/` directory.
