# Dashboard Data

This directory contains processed datasets used to build the Power BI dashboard.

## Included Files

| File | Purpose |
|---|---|
| `dashboard_category_summary.csv` | Category-level funnel and conversion metrics |
| `search_exploration.csv` | Search exploration and candidate-set analysis |
| `sensitivity_analysis.csv` | Sensitivity analysis across engagement thresholds |
| `purchase_opportunity.csv` | Benchmark comparison and illustrative purchase opportunity |

## Excluded Dataset

`product_metrics.csv` was used for detailed product-level diagnostics but is
excluded from the public repository because of its file size.

The Power BI report contains the imported data required for dashboard viewing.
